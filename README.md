# MindLock: The Manor of Mysteries

Room 1: The Clockmaker's Study. Static HTML/CSS/JavaScript game; no build step or backend required. Keep the assets folder beside index.html.

## GitHub Pages

Upload this folder's contents to the root of your repository. index.html must be at the repository root, not inside another folder.

In the repository: Settings > Pages > Build and deployment > Deploy from a branch. Select main and /(root), then Save. GitHub displays the published URL after deployment completes.

Game progress and scripted Keeper hint history save separately in each player's browser. The Keeper has no live AI connection. Original artwork and recorded chime are included; preserve their files when updating.
